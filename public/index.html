How to read this

  1. Same loop. Both runtimes import agent/core.py. Only the model call and the tool list differ.
  2. Cold start. The container boots on the first request and sleeps after two idle minutes. A Python Worker starts much faster than a container boots.
  3. Trace. Each row is one model call or one tool call, with its own duration. Tool rows show the arguments and the result.
  4. No keys in the container. It has no Internet. Its model calls go to ai.internal, which the gateway Worker intercepts and forwards to Workers AI.
